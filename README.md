I built two apps because the text in app2 was white, and I changed it to black in app3, and I also added a full-screen feature in app3.
Mentioned below are the controls for the app:
"ENTER" to add the character
"S" to speak current text
"BACKSPACE" to delete the last character
"SPACE" to add a space
"C" to clear text
"F" to toggle full screen
"Q / ESC" to quit
